# sir-multi-population

### Summary

R code to simulate a simple SIR model for three linked populations using `deSolve`.


### Guide to files

`scripts/Main_model_SIR.R` Main script to run plot and plot outputs

`R/Functions_SIR.R` SIR simulation functions

### Vignette

A detailed guide on how to implement the basic SIR model using the provided R code can be found in the vignette: [Implementing the Basic SIR Model](vignettes/implement_basic_model.html)
